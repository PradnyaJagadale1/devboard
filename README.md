# DevOps Nginx Demo

A simple DevOps project demonstrating the deployment of a static HTML webpage using Nginx on Ubuntu. This project is used to practice Git, GitHub, branching, merging, and basic web server configuration.

## Technologies Used

* Ubuntu
* Git & GitHub
* Nginx
* HTML

## Run Project

```bash
sudo systemctl start nginx
sudo cp index.html /var/www/html/
```

Open:

```text
http://<server-ip>
```

## Git Commands

```bash
git add .
git commit -m "Initial commit"
git push origin main
```

## Learning Outcomes

* Git Fundamentals
* Branching and Merging
* Pull Requests
* Rebase and Stash
* Revert and Reset
* Nginx Deployment
